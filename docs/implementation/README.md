# Implementation Index

这个目录收纳仓库内部实现解读与技术规格。

它和 `docs/product/` 的区别是：

- `docs/product/` 解释产品边界、能力定义、发布与路线
- `docs/implementation/` 解释代码层如何组织、如何执行、后续如何扩展

这层文档主要给仓库维护者使用，不属于公开产品叙事的一部分。
