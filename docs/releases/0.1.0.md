# VibeDocs 0.1.0

Release Date: 2026-03-13
Tag: `v0.1.0`
Package: `@leapx-ai/vibedocs`

## Summary

`0.1.0` is the first public open-core release of VibeDocs.

It establishes the free layer:

- reusable templates
- a full scaffold for project docs
- a local CLI
- a shared rule engine
- a first heuristic semantic audit layer
- a public docs site
- CI, Pages deployment, and package publish workflows

## Highlights

### Local CLI

The CLI now supports:

- `vibedocs init`
- `vibedocs feature create`
- `vibedocs audit`
- `vibedocs glossary check`

`vibedocs audit` also supports an initial `--semantic heuristic` mode for local content-level checks.

## Shared Rule Engine

The release includes:

- stable JSON report envelope
- local read-only rule packs
- diff-ready audit context
- initial `suggested_docs` mapping for changed paths
- first heuristic semantic checks for:
  - product content inside engineering docs
  - engineering content inside product docs
  - status leakage outside roadmap status
  - feature packages redefining global principles
  - glossary-like tables outside governance glossary
  - duplicate same-role definition sections between feature and global docs

## Reusable Assets

The repository ships:

- document templates
- `scaffold/docs/` starter system
- report and rule pack schemas
- example config and rule pack files

## Distribution and Docs

The package is prepared for public npm release as:
