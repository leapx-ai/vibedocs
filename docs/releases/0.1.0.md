# VibeDocs 0.1.0

Release Date: 2026-03-12
Tag: `v0.1.0`
Package: `@leapx-ai/vibedocs`

## Summary

`0.1.0` is the first public open-core release of VibeDocs.

It establishes the free layer:

- reusable templates
- a full scaffold for project docs
- a local CLI
- a shared rule engine
- a public docs site
- CI, Pages deployment, and package publish workflows

## Highlights

### Local CLI

The CLI now supports:

- `vibedocs init`
- `vibedocs feature create`
- `vibedocs audit`
- `vibedocs glossary check`

## Shared Rule Engine

The release includes:

- stable JSON report envelope
- local read-only rule packs
- diff-ready audit context
- initial `suggested_docs` mapping for changed paths

## Reusable Assets

The repository ships:

- document templates
- `scaffold/docs/` starter system
- report and rule pack schemas
- example config and rule pack files

## Distribution and Docs

The package is prepared for public npm release as:

- `@leapx-ai/vibedocs`

The public docs site is available on GitHub Pages and covers:

- product overview
- quickstart
- CLI usage
- concepts
- reference

## Verification

Release readiness is verified through:

- `npm run release:check`

That command includes:

- `npm test`
- `npm run pack:check`
- `npm run smoke:install`
