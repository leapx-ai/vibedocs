# VibeDocs 0.1.1

Release Date: 2026-03-13
Tag: `v0.1.1`
Package: `@leapx-ai/vibedocs`

## Summary

`0.1.1` is a patch release focused on package hygiene for the public npm distribution.

It does not add new CLI commands. It tightens what gets published and makes the npm-facing package metadata more user-oriented.

## Highlights

### Runtime-Only Package Contents

The npm tarball now ships only the assets required to run the tool:

- CLI entrypoint
- runtime source files
- bundled scaffold used by `init`
- bundled templates used by `feature create`
- license and npm-facing README

The package no longer includes internal repository materials that are not needed at runtime.

### Cleaner npm Presentation

The package README now focuses on:

- what VibeDocs is
- installation
- command usage
- config
- public documentation links

The package homepage now points to the public docs site instead of the repository README.

## Verification

Release readiness is verified through:

- `npm run release:check`

That command includes:

- `npm test`
- `npm run pack:check`
- `npm run smoke:install`
