# VibeDocs 0.1.2

Release Date: 2026-03-13
Tag: `v0.1.2`
Package: `@leapx-ai/vibedocs`

## Summary

`0.1.2` is a patch release focused on making the shipped package more usable for AI-assisted workflows after installation.

It adds packaged operating guides and reusable prompts so users do not need to return to the repository internals just to tell a model how to work with a VibeDocs project.

## Highlights

### Packaged AI Operating Guides

The npm package now includes a `guides/` directory with:

- `AI-OPERATING-PROTOCOL.md`
- `AI-EXECUTION-MODES.md`
- `MODEL-BOOTSTRAP-CONTRACT.md`

These guides define:

- how a model should load project context
- how it should identify SSOT documents
- how it should route updates
- how it should handle document status
- how humans should override or escalate decisions

### Packaged Reusable AI Prompts

The package now also includes:

- `AI-PROMPTS.md`

This guide provides reusable prompts for:

- bootstrapping a new docs system
- migrating a messy existing project
- creating a feature package
- syncing docs after an iteration
- reconciling docs before release
- checking terminology drift

### Clearer Lifecycle Guidance

The release also tightens the lifecycle contract across shipped assets:

- generate first
- complete second
- activate last

This makes the `Draft -> Active -> Snapshot -> Archive` path more explicit for both users and models.

## Verification

Release readiness is verified through:

- `npm run release:check`

That command includes:

- `npm test`
- `npm run pack:check`
- `npm run smoke:install`
