# VibeDocs 0.1.3

Release Date: 2026-03-13
Tag: `v0.1.3`
Package: `@leapx-ai/vibedocs`

## Summary

`0.1.3` is a patch release that closes a packaging-to-project gap in the AI workflow.

`guides/` was already shipped inside the npm package, but initialized projects did not yet receive those guides by default. This release fixes that mismatch.

## Highlights

### `init` Now Creates `guides/` By Default

Running:

- `vibedocs init --mode minimal`
- `vibedocs init --mode standard`
- `vibedocs init --mode full`

now creates both:

- `docs/`
- `guides/`

inside the target project.

This means models working inside the repo can directly access:

- `AI-OPERATING-PROTOCOL.md`
- `AI-EXECUTION-MODES.md`
- `MODEL-BOOTSTRAP-CONTRACT.md`
- `AI-PROMPTS.md`

without needing to look back into the installed package directory.

### Better End-to-End Validation

Smoke install verification now checks not only that the package installs, but also that an initialized project includes both:

- core docs
- project-local guides

## Verification

Release readiness is verified through:

- `npm run release:check`

That command includes:

- `npm test`
- `npm run pack:check`
- `npm run smoke:install`
