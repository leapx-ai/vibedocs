# VibeDocs 0.2.0

Release Date: 2026-04-12
Tag: `v0.2.0`
Package: `@leapx-ai/vibedocs`

## Summary

`0.2.0` turns VibeDocs into an agent-operable foundation release.

This version is not only about initializing docs and running audits. It introduces a first usable runtime workflow that can:

- classify changes
- route documentation work
- stop on human gates
- resume after decisions
- write reviewable draft updates
- emit stable machine-readable runtime reports

## Highlights

### Agent Runtime Workflow

VibeDocs now ships a runtime command set for human-in-the-loop agent work:

- `vibedocs runtime run`
- `vibedocs runtime decide`
- `vibedocs runtime resume`

This creates a practical execution loop:

1. run a task
2. stop on gates when human judgment is required
3. record the decision
4. resume with the recorded context

### Stable Runtime Report Contract

Runtime outputs now have a formal schema and IO helpers.

Reports include:

- classification
- routing
- gate outcomes
- resumed context
- draft write details
- audit verification summaries

Draft write details now include:

- target path
- action taken
- anchor heading
- insertion strategy

### Better Draft Writing

Draft writing is now more structured:

- document-type-specific draft content
- better section targeting
- clearer human review intent

Instead of appending the same generic block everywhere, runtime now produces more useful drafts for:

- `PRD`
- `TECH-SPEC`
- `ACCEPTANCE`
- `WIREFLOW`
- `ANALYTICS`
- `ROADMAP-STATUS`
- `GLOSSARY`

### Clearer Final Status Semantics

Runtime final status is now more expressive:

- `completed`
- `completed_with_draft_updates`
- `resumed`
- `resumed_with_draft_updates`
- `needs_human_decision`

This makes downstream tooling and review flows easier to build on top of VibeDocs.

### Packaged Runtime Guide

The npm package now includes:

- `guides/AGENT-RUNTIME.md`

This guide explains how to use runtime commands as a controlled agent workflow.
