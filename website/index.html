Workflow

Start with a docs system. Keep it from drifting.

1. Bootstrap

Generate a Minimal, Standard, or Full docs layout from the scaffold.

npx vibedocs init --mode minimal

2. Expand by feature

Create a feature package with PRD, wireflow, tech spec, acceptance, and analytics.

npx vibedocs feature create focus-mode

3. Audit continuously

Run diff-aware checks locally and get suggested docs touchpoints before you merge.

npx vibedocs audit --changed src/app.js
Why it works

The system is opinionated about structure, not about your stack.

Role × lifecycle model

Documentation is treated as a matrix of roles and lifecycle stages, not a single flat folder of notes.

SSOT by design

The system assumes documentation needs clear ownership and a declared single source of truth to avoid status drift.

Local rules first

The same result model can later feed hosted checks, but the free layer stays fully useful on its own.
