开源文档工具包

VibeDocs 让项目更容易把自己说清楚。

VibeDocs 是一套开源文档工具包，用来整理项目文档结构。 它提供可复用模板、可直接落仓库的 scaffold，以及本地 CLI， 帮你初始化文档系统、生成功能包并持续做巡检。

它是什么

一套小而稳的项目文档工具。

VibeDocs 尽量贴近普通文件工作流。你可以把它放进现有仓库里用， 不需要迁移到托管平台，也不需要学习新的编辑器。

怎么使用

先做这三步就够了。

1. 安装

把公共包装进仓库，使用本地命令开始操作。

npm install @leapx-ai/vibedocs

2. 生成文档

先建一套基线文档，再按真实功能继续扩展。

npx vibedocs init --mode minimal
npx vibedocs feature create focus-mode

3. 保持对齐

把 audit 和 glossary check 变成日常动作，而不是拖到发布前再补。

npx vibedocs audit --changed src/app.js
