稳定入口、schema 和 release 规则。

公共包暴露的表面故意保持克制。接口越小，越容易承诺稳定，也越容易让未来付费层建立在它之上，而不是绕开它。

区域 稳定契约 说明
包名 @leapx-ai/vibedocs 免费开源层对外发布的 npm 包。
命令 vibedocs 本地文档操作 CLI 入口。
公共导出 @leapx-ai/vibedocs
@leapx-ai/vibedocs/config
@leapx-ai/vibedocs/reporting
@leapx-ai/vibedocs/rule-engine 		新增可以做，但删除或重命名应按 breaking change 处理。
Report schema schemas/report.schema.json 结果中包含 diff 模式下的 suggested_docs 建议字段。
Rule pack schema schemas/rule-pack.schema.json 本地只读覆盖，允许调整 severity、suggestion、owner hint 或禁用规则。

发布规则

versioning 与发版流程

  • CLI、公共导出和 report schema 按 SemVer 管理。
  • CHANGELOG.md 必须跟 package.json 一起更新。
  • Git tag 格式：vX.Y.Z。
  • GitHub Release 触发 npm 包发布工作流。
